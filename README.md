# Visor de mapas – IA Tarapoto

Sitio de GitHub Pages: https://ia-tarapotodev.github.io/TARAPOTO-Dev/

Visor con zoom de los 3 mapas (circunscripción, corredores y red fluvial del Perú) (OpenSeadragon + teselas Deep Zoom generadas con `mapas/scripts/09_dzi.py`) y descarga de cada mapa en PDF (A0 vectorial) y en imagen liviana. Las fuentes de los mapas están en la rama `claude/waiting-for-files-4p16ta`.
